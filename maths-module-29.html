📘 MODULE 4: The ElGamal Cryptosystem

1. The Mathematical Foundation

Comprehensive Triad Comparison: RSA vs. Diffie-Hellman vs. ElGamal

Feature Diffie-Hellman (1976) RSA (1977) ElGamal (1985)
Underlying Hard Problem Discrete Logarithm Problem (DLP) Integer Factorization Problem (IFP) Discrete Logarithm Problem (DLP)
Primary Purpose Key Exchange / Agreement only Public-Key Encryption & Digital Signatures Public-Key Encryption & Digital Signatures
Ciphertext Expansion N/A (Negotiates symmetric key) 1:1 (Ciphertext same size as block) 2:1 (Produces pair \((c_1, c_2)\) — doubles message size)
Deterministic vs Probabilistic N/A Deterministic (Same \(m\) always yields same \(c\)) Probabilistic (Ephemeral random \(k\) yields different \(c\) each time)
Exam Note: Probabilistic encryption (ElGamal) prevents frequency analysis and chosen-plaintext dictionary attacks because encrypting "YES" twice produces two completely different ciphertexts!

The ElGamal cryptosystem (invented by Taher ElGamal in 1985) is based on the Discrete Logarithm Problem (just like Diffie-Hellman).

  • Easy: Given \(g\), \(p\), and \(x\), calculating \(y = g^x \bmod p\) is easy.
  • Hard: Given \(g\), \(p\), and \(y\), finding \(x\) is practically impossible.

Unlike RSA, where a single message can be encrypted to a single ciphertext block, ElGamal is probabilistic. This means that encrypting the same message twice will result in two completely different ciphertexts. This provides extra security but makes the ciphertext twice as large as the plaintext.

The ElGamal Cryptosystem: 4-Stage Complete Protocol Pipeline

PROBABILISTIC ENCRYPTION

Based on the Discrete Logarithm Problem (DLP). Every encryption incorporates an ephemeral random value \(k\), meaning encrypting the identical message twice yields different ciphertexts!

1 Key Generation
• Prime \(p\), primitive root \(g\)
• Private key: \(x \in (1, p-1)\)
• Compute: \(y = g^x mod p\)
Public: \((p, g, y)\)
Private: \(x\)
2 Encryption
• Random secret \(k \in (1, p-1)\)
• \(C_1 = g^k mod p\)
• \(C_2 = (M \cdot y^k) mod p\)
Ciphertext Pair: \((C_1, C_2)\)
3 Decryption
• Shared secret: \(S = C_1^x mod p\)
• Modular inverse: \(S^{-1} mod p\)
• Recover: \(M = (C_2 \cdot S^{-1}) mod p\)
Decrypted: \(M\) ✓
4 Proof of Correctness
\(S = (g^k)^x = g^{kx}\)
\(C_2 = M \cdot (g^x)^k = M \cdot g^{xk}\)
\(C_2 \cdot S^{-1} = (M \cdot g^{xk}) \cdot (g^{xk})^{-1} = M \pmod p\)
Q.E.D.

Complete line-by-line solution for ElGamal parameter setup, encryption, and decryption:

Question 1 (Numerical — 5 Marks) Parameters: \(p = 23, g = 5, x = 6\)

Given prime \(p = 23\) and generator \(g = 5\). Bob chooses private key \(x = 6\).
(a) Find Bob's public key \(y\).
(b) Alice encrypts message \(M = 10\) using random key \(k = 3\). Find ciphertext \((C_1, C_2)\).
(c) Show how Bob decrypts it.

(a) Bob's Public Key (\(y\))
• Formula: \(y = g^x mod p = 5^6 mod 23\)
• Line 1: \(5^2 = 25 \equiv 2 \pmod{23}\)
• Line 2: \(5^4 = 2^2 = 4 \pmod{23}\)
• Line 3: \(5^6 = 5^4 \cdot 5^2 = 4 \cdot 2 = \mathbf{8} \pmod{23}\)
⇒ Bob's Public Key: \((p=23, g=5, y=8)\)
(b) Alice Encrypts \(M = 10\) with \(k = 3\)
• Compute \(C_1\): \(C_1 = g^k mod p = 5^3 mod 23 = 125 mod 23\)
   Division: \(23 imes 5 = 115 \implies 125 - 115 = \mathbf{10} \implies C_1 = 10\)
• Compute \(C_2\): \(C_2 = (M \cdot y^k) mod p = (10 \cdot 8^3) mod 23\)
   Line 1: \(8^3 = 512\)
   Line 2: \(23 imes 22 = 506 \implies 512 - 506 = 6 \implies 8^3 \equiv 6 \pmod{23}\)
   Line 3: \(C_2 = (10 \cdot 6) = 60 mod 23\)
   Line 4: \(23 imes 2 = 46 \implies 60 - 46 = \mathbf{14} \implies C_2 = 14\)
⇒ Transmitted Ciphertext Pair: \((C_1, C_2) = (10, 14)\)
(c) Bob Decrypts with Private Key \(x = 6\)
• Line 1 (Compute Shared Secret): \(S = C_1^x mod p = 10^6 mod 23\)
   \(10^2 = 100 \equiv 8 \pmod{23}\)
   \(10^4 = 8^2 = 64 \equiv 18 \pmod{23}\)
   \(10^6 = 18 \cdot 8 = 144 = 23(6) + 6 \equiv \mathbf{6} \implies S = 6\)
• Line 2 (Find Modular Inverse \(S^{-1}\)): We solve \(6z \equiv 1 \pmod{23}\)
   \(6 imes 4 = 24 = 23 + 1 \equiv 1 \pmod{23} \implies \mathbf{S^{-1} = 4}\)
• Line 3 (Recover Message): \(M = (C_2 \cdot S^{-1}) mod p = (14 \cdot 4) mod 23 = 56 mod 23\)
   \(23 imes 2 = 46 \implies 56 - 46 = \mathbf{10}\)
⇒ Decrypted Message: \(M = 10\) ✓ (Perfect Match!)

1. Public key cryptography is based on:
Mathematical Explanation: Public key cryptography is based on trapdoor one-way functions.
2. If \(p = 7\) and \(q = 13\), what is \(\phi(n)\) where \(n = pq\)?
Mathematical Explanation: φ(n) = (7 - 1)(13 - 1) = 6 × 12 = 72.
3. In RSA, the public key is \((n, e)\). What is the private key?
Mathematical Explanation: In RSA, the private key is d where ed ≡ 1 (mod φ(n)).
4. In Diffie-Hellman, if Alice's private key is \(a\), Bob's is \(b\), and the base is \(g \bmod p\), what is the shared key?
Mathematical Explanation: In Diffie-Hellman, the shared secret key is K = g^{ab} mod p.
5. Which cryptosystem is probabilistic (produces different ciphertexts for the same message)?
Mathematical Explanation: ElGamal is probabilistic because every encryption uses a fresh random ephemeral key k.

Problem 1: ElGamal Key Gen, Encryption & Decryption (5 Marks) Given: \(p = 23, g = 5, x = 6, M = 10, k = 3\)
(a) Bob's Public Key \(y\)
\(y = g^x mod p = 5^6 mod 23\)
\(5^2 \equiv 2, \; 5^4 \equiv 4\)
\(5^6 = 4 imes 2 = \mathbf{8}\)
Public Key: \((23, 5, 8)\)
(b) Alice Encrypts \(M = 10\) (\(k = 3\))
\(C_1 = 5^3 mod 23 = 125 mod 23 = \mathbf{10}\)
\(C_2 = (10 \cdot 8^3) mod 23\)
\(8^3 = 512 = 23(22) + 6 \equiv 6\)
\(C_2 = (10 \cdot 6) = 60 \equiv \mathbf{14} \pmod{23}\)
Ciphertext: \((C_1, C_2) = (10, 14)\)
(c) Bob Decrypts with \(x = 6\)
\(S = C_1^x = 10^6 mod 23\)
\(10^2 \equiv 8, \; 10^4 \equiv 18, \; 10^6 = 18 \cdot 8 = 144 \equiv \mathbf{6}\)
Inverse \(S^{-1} \pmod{23}\): \(6 imes 4 = 24 \equiv 1 \implies S^{-1} = \mathbf{4}\)
\(M = (C_2 \cdot S^{-1}) = 14 \cdot 4 = 56 \equiv \mathbf{10} \pmod{23}\)
Recovered: \(M = 10\) ✓
Problem 2: RSA Complete Execution Cycle (10 Marks) Given: \(p = 5, q = 11, e = 3, M = 7\)
(a) Key Generation (3 Marks)
• Modulus: \(n = p imes q = 5 imes 11 = \mathbf{55}\)
• Totient: \(\phi(n) = (4)(10) = \mathbf{40}\)
• Check \(\gcd(3, 40) = 1\) (Valid)
• Private Key \(d\): Solve \(3d \equiv 1 \pmod{40}\)
\(3(27) = 81 = 2(40) + 1 \implies \mathbf{d = 27}\)
Public: \((55, 3)\) • Private: \(d = 27\)
(b) Message Encryption (3 Marks)
Formula: \(C = M^e mod n = 7^3 mod 55\)
\(7^3 = 343\)
Division: \(55 imes 6 = 330\)
\(343 - 330 = \mathbf{13}\)
Ciphertext: \(C = 13\)
(c) Decryption via Fast Exponentiation (4 Marks): \(M = 13^{27} mod 55\)

Binary of 27: \(27 = 16 + 8 + 2 + 1 = (11011)_2\). Calculate successive squares modulo 55:

Power Squaring Computation Modulo 55 Result Active Term?

Problem 3: ElGamal Numerical Full Lifecycle (10 Marks) Given: \(p = 19, g = 2, x = 5, M = 8, k = 3\)
(a) Public Key Derivation (2 Marks)
\(y = g^x mod p = 2^5 mod 19\)
\(2^5 = 32 = 19 + 13\)
Public Key: \((p=19, g=2, y=13)\)
(b) Encryption of \(M = 8\) (4 Marks)
\(C_1 = 2^3 mod 19 = \mathbf{8}\)
\(C_2 = (8 \cdot 13^3) mod 19\)
\(13^2 = 169 \equiv 17 \equiv -2\)
\(13^3 = -2 \cdot 13 = -26 \equiv 12\)
\(C_2 = 8 \cdot 12 = 96 = 5(19) + 1 = \mathbf{1}\)
Ciphertext: \((C_1, C_2) = (8, 1)\)
(c) Decryption Execution (4 Marks)
\(S = C_1^x = 8^5 mod 19\)
\(8^2 = 64 \equiv 7, \; 8^4 = 49 \equiv 11\)
\(8^5 = 11 \cdot 8 = 88 \equiv \mathbf{12}\)
Inverse \(12^{-1} \pmod{19}\): \(12 imes 8 = 96 \equiv 1 \implies S^{-1} = \mathbf{8}\)
\(M = (C_2 \cdot S^{-1}) = 1 \cdot 8 = \mathbf{8}\)
Decrypted: \(M = 8\) ✓
