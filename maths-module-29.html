📘 MODULE 4: The ElGamal Cryptosystem

1. The Mathematical Foundation

Comprehensive Triad Comparison: RSA vs. Diffie-Hellman vs. ElGamal

Feature Diffie-Hellman (1976) RSA (1977) ElGamal (1985)
Underlying Hard Problem Discrete Logarithm Problem (DLP) Integer Factorization Problem (IFP) Discrete Logarithm Problem (DLP)
Primary Purpose Key Exchange / Agreement only Public-Key Encryption & Digital Signatures Public-Key Encryption & Digital Signatures
Ciphertext Expansion N/A (Negotiates symmetric key) 1:1 (Ciphertext same size as block) 2:1 (Produces pair \((c_1, c_2)\) — doubles message size)
Deterministic vs Probabilistic N/A Deterministic (Same \(m\) always yields same \(c\)) Probabilistic (Ephemeral random \(k\) yields different \(c\) each time)
Exam Note: Probabilistic encryption (ElGamal) prevents frequency analysis and chosen-plaintext dictionary attacks because encrypting "YES" twice produces two completely different ciphertexts!

The ElGamal cryptosystem (invented by Taher ElGamal in 1985) is based on the Discrete Logarithm Problem (just like Diffie-Hellman). * Easy: Given \(g\), \(p\), and \(x\), calculating \(y = g^x \bmod p\) is easy. * Hard: Given \(g\), \(p\), and \(y\), finding \(x\) is practically impossible.

Unlike RSA, where a single message can be encrypted to a single ciphertext block, ElGamal is probabilistic. This means that encrypting the same message twice will result in two completely different ciphertexts. This provides extra security but makes the ciphertext twice as large as the plaintext.

2. ElGamal Key Generation (Step-by-Step)

  1. Choose a large prime \(p\) and a generator \(g\) (a primitive root modulo \(p\)).
  2. Choose a private key \(x\) such that \(1 \lt x \lt p-1\).
  3. Compute the public key \(y\):
\[y = g^x \bmod p\]
*   **Public Key:** \((p, g, y)\)
*   **Private Key:** \(x\)

3. ElGamal Encryption

To encrypt a message \(M\) (where \(M\) is an integer \(0 \le M \lt p\)): 1. The sender chooses a random secret number \(k\) such that \(1 \lt k \lt p-1\). 2. The sender computes two values (the ciphertext is a pair \((C_1, C_2)\)):

\[C_1 = g^k \bmod p\]
\[C_2 = (M \cdot y^k) \bmod p\]
  1. The sender sends the pair \((C_1, C_2)\) to the receiver.

4. ElGamal Decryption

The receiver uses their private key \(x\) to recover the message: 1. Compute the shared secret: \(S = C_1^x \bmod p\). 2. Compute the modular inverse of \(S\): \(S^{-1} \bmod p\). 3. Recover the message:

\[M = (C_2 \cdot S^{-1}) \bmod p\]

Mathematical Proof of Decryption (Why it works): \(S = C_1^x = (g^k)^x = g^{kx} \bmod p\). \(C_2 = M \cdot y^k = M \cdot (g^x)^k = M \cdot g^{xk} \bmod p\). Therefore, \(C_2 \cdot S^{-1} = (M \cdot g^{xk}) \cdot (g^{xk})^{-1} = M \bmod p\).

📝 Solved Exam Questions for ElGamal

Question 1 (Numerical - 5 Marks): Let \(p = 23\), \(g = 5\). Bob chooses private key \(x = 6\). (a) Find Bob's public key \(y\). (b) Alice wants to send the message \(M = 10\). She chooses random \(k = 3\). Find the ciphertext \((C_1, C_2)\). (c) Show how Bob decrypts it. Solution: (a) \(y = g^x \bmod p = 5^6 \bmod 23\). From Module 2, we know \(5^2 \equiv 2\), \(5^4 \equiv 4\). So \(5^6 = 4 \times 2 = 8\). Public Key: \((p=23, g=5, y=8)\).

(b) Alice encrypts \(M = 10\) with \(k = 3\): \(C_1 = g^k \bmod p = 5^3 \bmod 23 = 125 \bmod 23\). (\(23 \times 5 = 115\), so \(125 - 115 = 10\)). \(C_1 = 10\). \(C_2 = (M \cdot y^k) \bmod p = (10 \cdot 8^3) \bmod 23\). \(8^3 = 512\). \(512 \bmod 23\): \(23 \times 22 = 506\). \(512 - 506 = 6\). \(C_2 = (10 \cdot 6) \bmod 23 = 60 \bmod 23\). (\(23 \times 2 = 46\), \(60 - 46 = 14\)). \(C_2 = 14\). Ciphertext: \((10, 14)\).

(c) Bob decrypts \((10, 14)\) with private key \(x = 6\): \(S = C_1^x \bmod p = 10^6 \bmod 23\). \(10^2 = 100 \equiv 8 \pmod{23}\). \(10^4 = 8^2 = 64 \equiv 18 \pmod{23}\). \(10^6 = 10^4 \cdot 10^2 = 18 \cdot 8 = 144 \pmod{23}\). \(23 \times 6 = 138\). \(144 - 138 = 6\). So, \(S = 6\).

Now we need the inverse of \(6 \pmod{23}\). We need \(6z \equiv 1 \pmod{23}\). \(6 \times 4 = 24 \equiv 1 \pmod{23}\). So, \(S^{-1} = 4\).

\(M = (C_2 \cdot S^{-1}) \bmod p = (14 \cdot 4) \bmod 23 = 56 \bmod 23\). \(23 \times 2 = 46\). \(56 - 46 = 10\). Decrypted Message: \(M = 10\). (Matches!)

1. Public key cryptography is based on:
Mathematical Explanation: Public key cryptography is based on trapdoor one-way functions.
2. If \(p = 7\) and \(q = 13\), what is \(\phi(n)\) where \(n = pq\)?
Mathematical Explanation: φ(n) = (7 - 1)(13 - 1) = 6 × 12 = 72.
3. In RSA, the public key is \((n, e)\). What is the private key?
Mathematical Explanation: In RSA, the private key is d where ed ≡ 1 (mod φ(n)).
4. In Diffie-Hellman, if Alice's private key is \(a\), Bob's is \(b\), and the base is \(g \bmod p\), what is the shared key?
Mathematical Explanation: In Diffie-Hellman, the shared secret key is K = g^{ab} mod p.
5. Which cryptosystem is probabilistic (produces different ciphertexts for the same message)?
Mathematical Explanation: ElGamal is probabilistic because every encryption uses a fresh random ephemeral key k.
