# **Unit IV — Module 5: Vigenère Cipher**

Primary reference: Rosen, *Number Theory and Cryptography*, Section 4.6, pages 297–298 and Exercises 18–22, page 305.

The Vigenère cipher is an important extension of the shift cipher. Instead of using one fixed shift for every letter, it uses a **keyword containing multiple shifts**.

This makes it a polyalphabetic substitution method: the same plaintext letter can be encrypted into different ciphertext letters depending on its position and the corresponding key letter.

We'll follow Rosen's method, including its numerical example using the keyword RED and plaintext ORANGE.&#x20;

U456 (Textbook content) MTH381.pdf



## **5.1 What is the Vigenère cipher?**

The Vigenère cipher is a block cipher that uses a key string of letters.

Suppose the key is:

\\[ \text{RED} \\]

Convert the key letters into numbers:

\\[ R=17,\quad E=4,\quad D=3. \\]

The key therefore represents the sequence:

\\[ \boxed{17,\ 4,\ 3} \\]

Each plaintext letter is shifted by the corresponding key number.

- First letter: shift by 17.
- Second letter: shift by 4.
- Third letter: shift by 3.
- Fourth letter: shift by 17 again.
- Fifth letter: shift by 4 again.
- Sixth letter: shift by 3 again.

The key repeats until the entire plaintext is encrypted.

This repetition is the central feature of the Vigenère cipher.

## **5.3 Vigenère encryption formula**

Suppose:

- The plaintext block has numerical values \\(p_1,p_2,\ldots,p_m\\).
- The key has numerical values \\(k_1,k_2,\ldots,k_m\\).
- The ciphertext block has numerical values \\(c_1,c_2,\ldots,c_m\\).

Rosen defines the ciphertext block as:

\\[ \boxed{c_i=(p_i+k_i)\bmod26} \\]

for each position \\(i=1,2,\ldots,m\\).

In expanded form:

\\[ \boxed{ \begin{aligned} c_1&=(p_1+k_1)\bmod26\\\ c_2&=(p_2+k_2)\bmod26\\\ c_3&=(p_3+k_3)\bmod26\\\ &\ \vdots\\\ c_m&=(p_m+k_m)\bmod26 \end{aligned} } \\]

Each position uses its corresponding key value.

### **How is this different from a shift cipher?**

In a shift cipher:

\\[ c_i=(p_i+k)\bmod26 \\]

The same \\(k\\) is used at every position.

In the Vigenère cipher:

\\[ c_i=(p_i+k_i)\bmod26 \\]

The key value can change from one position to another.

## **5.6 Vigenère decryption formula**

Encryption adds the key value:

\\[ c_i=(p_i+k_i)\bmod26. \\]

To recover the plaintext, subtract the corresponding key value:

\\[ \boxed{p_i=(c_i-k_i)\bmod26} \\]

This is the decryption formula.

### **Why does subtraction work?**

Starting from:

\\[ c_i\equiv p_i+k_i\pmod{26} \\]

Subtract \\(k_i\\):

\\[ c_i-k_i\equiv p_i\pmod{26}. \\]

Therefore:

\\[ \boxed{p_i=(c_i-k_i)\bmod26}. \\]

Unlike the affine cipher, the Vigenère cipher does not require finding a multiplicative inverse. It uses modular addition and subtraction.

## **5.7 Complete decryption example: Decrypt FVDEKH using RED**

Given:

\\[ C=\text{FVDEKH} \\]

\\[ K=\text{RED} \\]

Repeat the key:

\\[ \text{REDRED} \\]

### **Step 1: Convert ciphertext into numbers**

\\[ F=5,\ V=21,\ D=3,\ E=4,\ K=10,\ H=7. \\]

So:

\\[ C=5,\ 21,\ 3,\ 4,\ 10,\ 7. \\]

### **Step 2: Convert the key into numbers**

\\[ K=17,\ 4,\ 3,\ 17,\ 4,\ 3. \\]

### **Step 3: Apply decryption**

\\[ p_i=(c_i-k_i)\bmod26. \\]

For the first letter:

\\[ p_1=(5-17)\bmod26 \\]

\\[ =-12\bmod26=14. \\]

14 represents O.

For the second letter:

\\[ p_2=(21-4)\bmod26=17. \\]

17 represents R.

For the third letter:

\\[ p_3=(3-3)\bmod26=0. \\]

0 represents A.

For the fourth letter:

\\[ p_4=(4-17)\bmod26 =-13\bmod26=13. \\]

13 represents N.

For the fifth letter:

\\[ p_5=(10-4)\bmod26=6. \\]

6 represents G.

For the sixth letter:

\\[ p_6=(7-3)\bmod26=4. \\]

4 represents E.

## **5.8 Vigenère tableau**

The Vigenère tableau is a tabular method of performing the same modular addition.

Each row represents a shift, and each column represents a plaintext letter.

For example:

- Row A represents shift 0.
- Row B represents shift 1.
- Row C represents shift 2.
- Row R represents shift 17.

To encrypt a letter, locate the row corresponding to the key letter and the column corresponding to the plaintext letter. The intersection gives the ciphertext letter.

### **Example: Encrypt O using key R**

- Plaintext O corresponds to column O.
- Key R corresponds to row R.
- The intersection is F.

Therefore:

\\[ O+R\rightarrow F. \\]

**First few rows of the Vigenère tableau**

Columns are plaintext letters; rows are key letters.

| Key \ Plaintext | A | B | C | D | E | F |
| --------------- | - | - | - | - | - | - |
| A               | A | B | C | D | E | F |
| B               | B | C | D | E | F | G |
| C               | C | D | E | F | G | H |
| D               | D | E | F | G | H | I |
| E               | E | F | G | H | I | J |
| F               | F | G | H | I | J | K |

The full tableau has 26 rows and 26 columns. It is simply a visual representation of addition modulo 26.

## **5.9 Why is Vigenère stronger than a shift cipher?**

In a shift cipher, the same plaintext letter always becomes the same ciphertext letter.

For example, with key 3:

\\[ A\rightarrow D \\]

Every occurrence of A becomes D.

In the Vigenère cipher, the shift depends on the corresponding key letter.

For example, plaintext A can become:

- R if the key letter is R.
- E if the key letter is E.
- D if the key letter is D.

Thus, the same plaintext letter can produce different ciphertext letters.

**The important consequence:** The ordinary single-letter frequency pattern of the plaintext is obscured because one plaintext letter may be encrypted differently at different positions.

Rosen notes that frequency information is obscured, but not all information about plaintext structure disappears.&#x20;

## **5.10 Cryptanalysis of the Vigenère cipher**

Cryptanalysis means recovering the original plaintext without knowing the encryption key.

Breaking the Vigenère cipher is more difficult than breaking a simple shift cipher because the key changes the shift from one position to another.

Rosen describes two main stages:

1. Determine the length of the key string.
2. Determine each character of the key string by identifying its corresponding shift.

U456 (Textbook content) MTH381.pdf

### **Stage 1: Determine the key length**

Suppose the same sequence of letters appears several times in a long ciphertext.

This repetition can provide clues about the length of the repeating keyword.

Why?

Because the same plaintext sequence encrypted under the same sequence of key letters produces the same ciphertext sequence.

If the repeated ciphertext sequence occurs at positions separated by a multiple of the key length, the distance between those positions may reveal information about the key length.

**Illustrative example:**

Suppose a repeated ciphertext sequence starts at positions 10 and 28.

The distance is:

\\[ 28-10=18. \\]

The key length may be a divisor of 18:

\\[ 1,\ 2,\ 3,\ 6,\ 9,\ 18. \\]

Other repeated sequences and their distances can help narrow down the likely key length.

**Important:** One repeated sequence does not prove the key length. The distances provide clues, and several repetitions should be examined.

### **Stage 2: Determine each key character**

Suppose we have established that the keyword has length 3.

Then the ciphertext can be separated into three groups:

- Group 1: ciphertext letters encrypted with key position 1.
- Group 2: ciphertext letters encrypted with key position 2.
- Group 3: ciphertext letters encrypted with key position 3.

Each group was encrypted using one fixed shift.

Therefore, we can apply frequency analysis separately to each group.

For example, if the first group appears to have been shifted by 5, the first key letter is F because:

\\[ F=5. \\]

Repeat the analysis for the other two groups to recover the remaining key letters.

Rosen emphasizes that this method assumes the plaintext is sufficiently long for its letter frequencies to be reasonably close to typical English frequencies.&#x20;

U456 (Textbook content) MTH381.pdf



### **Why can frequency analysis work after finding the key length?**

The Vigenère cipher initially uses different shifts across the message.

But after separating the ciphertext by key position, each group uses one fixed shift.

This converts the problem into several ordinary shift-cipher cryptanalysis problems.

**Vigenère cryptanalysis — overall process**

**Intercepted ciphertext**

**Find repeated sequences and their positions**

**Estimate the key length**

**Separate ciphertext into groups by key position**

**Apply frequency analysis to each group**

**Recover key characters and decrypt**

## **5.11 Vigenère cipher versus shift and affine ciphers**

| Feature                  | Shift            | Affine                      | Vigenère                            |
| ------------------------ | ---------------- | --------------------------- | ----------------------------------- |
| Main operation           | Addition         | Multiplication and addition | Repeated modular addition           |
| Key                      | One integer      | Two integers                | String of letters                   |
| Key changes by position? | No               | No                          | Yes                                 |
| Encryption               | \\(p+k\\)        | \\(ap+b\\)                  | \\(p_i+k_i\\)                       |
| Modulus                  | 26               | 26                          | 26                                  |
| Modular inverse needed?  | No               | Yes, for \\(a\\)            | No                                  |
| Cipher type              | Character cipher | Character cipher            | Block cipher in Rosen's terminology |
| Frequency pattern        | Preserved        | Preserved                   | Obscured                            |

All three use modular arithmetic, but they apply it differently.

## **5.12 Important formulas and examination points**

**Vigenère encryption**

\\[ \boxed{c_i=(p_i+k_i)\bmod26} \\]

**Vigenère decryption**

\\[ \boxed{p_i=(c_i-k_i)\bmod26} \\]

**Key conversion**

\\[ A=0,\ B=1,\ldots,Z=25 \\]

**Key repetition**

If the keyword has length \\(m\\), repeat its numerical sequence until the entire plaintext is covered.

**Cryptanalysis**

1. Estimate key length from repeated ciphertext sequences.
2. Determine each key character by frequency analysis of the corresponding group.

### **Common MCQ traps**

1. Vigenère uses a string of letters as its key.
2. The key is repeated to cover the plaintext.
3. Encryption uses addition modulo 26.
4. Decryption uses subtraction modulo 26.
5. The key values are aligned position by position.
6. Spaces normally do not consume key positions.
7. A Vigenère cipher can encrypt the same plaintext letter differently.
8. It obscures ordinary single-letter frequency information.
9. It is called a block cipher in Rosen's terminology.
10. The Vigenère tableau implements modular addition.
11. Finding the key length is the first stage of the cryptanalysis described by Rosen.
12. Once the key length is known, each key position can be analyzed as a shift cipher.
