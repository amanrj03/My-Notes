Number Theory-III · Based on Rosen, Number Theory and Cryptography, Chapter 4

Rosen identifies several practical applications of number theory: generating pseudorandom numbers, assigning memory locations to computer files, constructing check digits to detect errors, and encrypting messages.

We'll focus on the mathematical principles and calculations, not programming.

16.1 Application 1: Pseudorandom number generation

A pseudorandom number sequence is generated by a deterministic mathematical rule but is designed to resemble a random sequence.

One common mathematical model is the linear congruential generator:

\[\boxed{x_{n+1}\equiv ax_n+c\pmod m}\]

where:

  • \(x_n\) is the current value.
  • \(a\) is the multiplier.
  • \(c\) is the increment.
  • \(m\) is the modulus.
  • \(x_{n+1}\) is the next value, represented by a remainder between \(0\) and \(m-1\).
💡 WORKED EXAMPLE
Worked example

Suppose

\[x_{n+1}\equiv(5x_n+3)\pmod{16}, \qquad x_0=2.\]

Find the next four values.

First value:

\[x_1=(5\cdot2+3)\bmod16=13.\]

Second value:

\[x_2=(5\cdot13+3)\bmod16 =68\bmod16=4.\]

Third value:

\[x_3=(5\cdot4+3)\bmod16=23\bmod16=7.\]

Fourth value:

\[x_4=(5\cdot7+3)\bmod16 =38\bmod16=6.\]

The sequence is

\[\boxed{2,\ 13,\ 4,\ 7,\ 6,\ldots}\]

Each value is determined by the previous one. Because there are only \(m\) possible states, the sequence must eventually repeat.

MCQ point: Pseudorandom does not mean truly random. A deterministic generator with a fixed initial value and fixed parameters produces the same sequence every time.

16.2 Application 2: Assigning memory locations

Congruences can also be used to assign a value to a fixed range of possible locations. A mathematical model is to reduce a number modulo \(m\).

For example, consider the assignment rule

\[h(k)=k\bmod 10.\]

It assigns each integer \(k\) a remainder from \(0\) to \(9\).

Integer \(k\) Assigned value \(h(k)\)
123 3
458 8
763 3
129 9

Notice that \(123\) and \(763\) both map to \(3\). This is a collision: two different inputs are assigned the same location.

The general mathematical idea is that modular reduction maps a large set of integers into a smaller set of possible values. Rosen discusses assigning memory locations to computer files as one application of congruences.

MCQ traps:

  • Different integers can have the same remainder modulo \(m\).
  • With this rule, there are exactly \(m\) possible outputs: \(0,1,\ldots,m-1\).
  • A collision does not mean the congruence calculation is incorrect.

16.3 Application 3: Check digits

A check digit is an extra digit added to an identification number to help detect errors when the number is entered or copied. Check-digit systems use arithmetic rules, often involving remainders.

The exact detection guarantees depend on the particular rule: not every check-digit system catches every possible error.

A simple check-digit scheme

Consider a number with digits \(d_1,d_2,d_3\). Define the check digit \(c\) by

\[c\equiv d_1+d_2+d_3\pmod{10}, \qquad 0\le c\le9.\]

For the number \(274\),

\[c\equiv2+7+4=13\equiv3\pmod{10}.\]

So the complete number is \(2743\), where the last digit is the check digit.

To verify it, calculate

\[2+7+4\equiv3\pmod{10}.\]

The check digit matches, so the number passes this simple check.

If the first digit is accidentally changed from \(2\) to \(5\), the sum becomes

\[5+7+4=16\equiv6\pmod{10}.\]

The expected check digit is now \(6\), not \(3\), so the error is detected.

Important limitation: This simple rule can miss some errors. For example, changing \(274\) to \(364\) leaves the digit sum unchanged. Real check-digit systems use rules chosen to catch particular types of errors.

Rosen identifies check digits in identification numbers as an application of number theory.

16.4 Summary: When do these applications use congruences?

Application Mathematical idea Main purpose
Pseudorandom numbers \(x_{n+1}\equiv ax_n+c\pmod m\) Generate a repeatable sequence
Memory locations \(h(k)=k\bmod m\) Map inputs to a finite set of locations
Check digits A digit condition modulo \(m\) Detect certain data-entry errors

These are the three applications to focus on from the topics identified in Rosen's chapter overview.
