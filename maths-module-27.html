Welcome to Module 2: The Diffie-Hellman Key Exchange.

In Module 1, we learned that Private Key Cryptography has a major flaw: How do Alice and Bob share the secret key securely in the first place? If they send it over the internet, a hacker (Eve) can intercept it.

The Diffie-Hellman Key Exchange (1976) was the first practical mathematical solution to this problem. It allows two parties to agree on a shared secret key over a public channel, without ever sending the key itself.

1. The Mathematics Behind Diffie-Hellman

Diffie-Hellman relies on a mathematical trapdoor called the Discrete Logarithm Problem (DLP).

Here is the core idea:

  • Easy: Calculating \(g^a \pmod p\) is computationally easy (using fast modular exponentiation, which we learned in Module 1).
  • Hard: If I give you \(g\), \(p\), and the result \(Y = g^a \pmod p\), it is practically impossible to find the exponent \(a\) (especially when \(p\) is a very large prime). This is because logarithms in modular arithmetic have no easy formula; you essentially have to guess and check.

2. The Protocol (Step-by-Step for Exams)

Diffie-Hellman Key Exchange Protocol Architecture

Public Domain Parameters: Large Prime \(p\) and Primitive Root (Generator) \(g \bmod p\)
Alice
1. Chooses private secret: \(a\)
2. Computes public key:
\(A = g^a \bmod p\)
3. Receives Bob's public key \(B\)
4. Computes shared session key:
\(K = B^a \bmod p\)
Alice sends \(A\) →
← Bob sends \(B\)
Bob
1. Chooses private secret: \(b\)
2. Computes public key:
\(B = g^b \bmod p\)
3. Receives Alice's public key \(A\)
4. Computes shared session key:
\(K = A^b \bmod p\)
Mathematical Identity: \(K = (g^b)^a \equiv g^{ab} \equiv (g^a)^b \pmod p\). Both arrive at the identical key!

Before the exchange begins, Alice and Bob agree on two public numbers (they can shout these across the room):

  1. \(p\): A large prime number.
  2. \(g\): A primitive root modulo \(p\) (a generator). For exam purposes, \(g\) is just a small integer less than \(p\) (like 2, 3, or 5).

The Exchange:

  1. Alice chooses a secret private number \(a\) (she keeps this in her head).
  2. Bob chooses a secret private number \(b\) (he keeps this in his head).
  3. Alice computes her public value: \(A = g^a \pmod p\). She sends \(A\) to Bob.
  4. Bob computes his public value: \(B = g^b \pmod p\). He sends \(B\) to Alice.

(Note: Even if a hacker intercepts \(A\) and \(B\), they cannot find \(a\) or \(b\) because of the Discrete Logarithm Problem).

  1. Alice computes the Shared Secret Key (\(K\)): She takes Bob's public value (\(B\)) and raises it to her private number (\(a\)):
\[K = B^a \pmod p\]
  1. Bob computes the Shared Secret Key (\(K\)): He takes Alice's public value (\(A\)) and raises it to his private number (\(b\)):
\[K = A^b \pmod p\]

Why do they get the same key? (You must write this proof in a 10-mark question!) Because of the laws of exponents: \(K = B^a = (g^b)^a = g^{ab} \pmod p\) \(K = A^b = (g^a)^b = g^{ab} \pmod p\) Both get \(g^{ab} \pmod p\). They now share the exact same key, and no one else knows it!

3. Solved Exam Questions

Let's look at how this is tested.

Question 1 (MCQ - 1 Mark): In the Diffie-Hellman protocol, if Alice's private key is \(a\), Bob's private key is \(b\), and the public base is \(g\) modulo prime \(p\), what is the shared secret key?

  • A) \(g^a + g^b \pmod p\)
  • B) \(g^{a+b} \pmod p\)
  • C) \(g^{ab} \pmod p\)
  • D) \(a \cdot b \pmod p\) Answer: C

Question 2 (Numerical — 5 Marks): Diffie-Hellman Calculation Walkthrough

5-MARK SOLVED EXAM QUESTION

Alice and Bob execute Diffie-Hellman with public prime \(p = 23\) and base generator \(g = 5\). Alice chooses private key \(a = 6\); Bob chooses private key \(b = 15\). Find the public keys exchanged and the derived shared secret key.

1 Alice's Public Key (\(A\))
Formula: \(A = g^a \pmod p = 5^6 \pmod{23}\)
• \(5^2 = 25 \equiv 2 \pmod{23}\)
• \(5^4 = 2^2 = 4 \pmod{23}\)
• \(5^6 = 5^4 \cdot 5^2 = 4 \cdot 2 = \mathbf{8} \pmod{23}\)
Alice Public Key: \(A = 8\)
2 Bob's Public Key (\(B\))
Formula: \(B = g^b \pmod p = 5^{15} \pmod{23}\)
• Binary: \(15 = 8 + 4 + 2 + 1\)
• Powers: \(5^1 = 5, \; 5^2 = 2, \; 5^4 = 4, \; 5^8 = 4^2 = 16\)
• \(5^{15} = 16 \cdot 4 \cdot 2 \cdot 5 = 640 \pmod{23}\)
• Division: \(23 imes 27 = 621 \implies 640 - 621 = \mathbf{19}\)
Bob Public Key: \(B = 19\)
3 Shared Secret (Alice Computes)
\(K = B^a \pmod p = 19^6 \pmod{23}\)
Negative Congruence: \(19 \equiv -4 \pmod{23}\)
\((-4)^6 = 4^6 = (4^3)^2 = 64^2\)
\(64 \equiv 18 \pmod{23}\) (since \(23 imes 2 = 46\))
\(18^2 = 324 = 23 imes 14 + 2 \equiv \mathbf{2} \pmod{23}\)
4 Shared Secret (Bob Computes & Check)
\(K = A^b \pmod p = 8^{15} \pmod{23}\)
Notice \(8 = 2^3 \implies 8^{15} = (2^3)^{15} = 2^{45} \pmod{23}\)
By FLT: \(2^{22} \equiv 1 \pmod{23}\)
\(2^{45} = (2^{22})^2 \cdot 2^1 \equiv 1^2 \cdot 2 = \mathbf{2} \pmod{23}\)
✓ Mutual Verification Complete: \(K_{Alice} = K_{Bob} = 2\). Shared Secret Key established successfully!

4. Security Analysis (For Theoretical Marks)

Why is it secure? An attacker (Eve) knows \(p, g, A,\) and \(B\). She needs to find \(a\) or \(b\). To find \(a\), she must solve \(A = g^a \pmod p\). This is the Discrete Logarithm Problem. For a large prime \(p\) (e.g., 2048 bits), this takes billions of years with current computers.

Vulnerability (Man-in-the-Middle Attack): Diffie-Hellman is secure against eavesdropping, but it is vulnerable to a Man-in-the-Middle (MITM) attack because it lacks authentication. Eve can intercept Alice's public key and send her own to Bob, and vice versa. Alice and Bob will end up sharing a key with Eve, not each other. Exam Note: If asked how to fix this, the answer is to use Digital Signatures (which we will not cover in detail here) or a Public Key Infrastructure (PKI) to authenticate the public keys.

1. On which computationally hard problem does the Diffie-Hellman key exchange rely?
Mathematical Explanation: Diffie-Hellman relies on the computational intractability of the Discrete Logarithm Problem (DLP) in ℤ_p*.
2. What is a primitive root modulo prime p?
Mathematical Explanation: A primitive root modulo p generates all p - 1 non-zero elements of ℤ_p through its successive powers.
3. In Diffie-Hellman, which parameters are transmitted openly over the public channel?
Mathematical Explanation: Alice and Bob transmit public parameters (p, g) and public keys A = g^a mod p and B = g^b mod p openly over the insecure channel.
4. If p = 23, g = 5, and Alice chooses private secret a = 6, what is Alice's public key A?
Mathematical Explanation: A = 5⁶ mod 23 = 15625 mod 23 = 8.
5. If Bob's public key is B = 19, Alice's secret is a = 6, and p = 23, what is shared key K = B^a mod p?
Mathematical Explanation: K = B^a mod p = 19⁶ mod 23 = 2.
6. What major security vulnerability affects basic unauthenticated Diffie-Hellman?
Mathematical Explanation: Pure unauthenticated Diffie-Hellman is vulnerable to a Man-in-the-Middle (MITM) attack because neither party authenticates their public key.
7. The difficulty of computing g^(ab) mod p given only g^a mod p and g^b mod p is known as:
Mathematical Explanation: The difficulty of computing g^{ab} mod p from g^a and g^b is the Computational Diffie-Hellman (CDH) problem.
8. How can Diffie-Hellman be authenticated to prevent MITM attacks?
Mathematical Explanation: MITM attacks are mitigated by binding public keys to digital signatures or certificates verified through a PKI.
